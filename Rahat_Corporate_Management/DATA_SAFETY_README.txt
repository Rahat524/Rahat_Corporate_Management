V6 DATA SAFETY
==============
1. Data is stored permanently in:
   %LOCALAPPDATA%\RahatCorporateManagement\corporate_scrap.db
2. On first run, V6 automatically searches older project folders and migrates the database containing the most records.
3. A daily automatic backup is saved in:
   %LOCALAPPDATA%\RahatCorporateManagement\Backups
4. Latest 30 automatic backups are retained.
5. Settings > Permanent Data, Backup & Restore lets an authorized user download or restore a backup.
6. Before restore, the current database is backed up automatically.
