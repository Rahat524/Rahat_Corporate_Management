LOGIN / RENDER DATABASE FIX - 06-AUG-2026

Fixed error:
  sqlite3.OperationalError: no such table: users
  POST /api/login returned HTTP 500

Cause:
Render starts the website with Gunicorn using app:app. The previous code only
ran init_db() inside the __main__ block, so database tables were created during
local `python app.py` startup but not during Render/Gunicorn startup.

Fix:
The application now runs init_db() automatically when app.py is imported by
Gunicorn. The users table and default Rahat administrator are therefore created
before the first login request.
